# BloomDays – Daily Habit Tracker

BloomDays is a React Native app built with Expo for my Mobile Communication and Computing ICA. It helps users plan daily routines, check off habits, and track their progress.

## Features I added

Time-of-day groups — Choose Morning, Afternoon, Evening, or Anytime when creating or editing a habit. Today groups scheduled habits by that choice.

Target time and duration — Set an optional time and duration, such as `16:00 · 25 min`. Both values appear on Today and My Habits.

Check-in history — Habit Details shows completed and missed check-ins from the last seven days. Rest days and pending check-ins for today are excluded from missed days.

Monthly progress calendar — Switch between weekly and monthly reports. The calendar uses colors to show complete, partial, missed, pending, unscheduled, and upcoming days.

## App screens

| Screen | What it does |
| --- | --- |
| Today | Shows today's scheduled habits and lets users mark them complete or undo a check-in. |
| My Habits | Shows the weekly plan and lets users search and filter habits by weekday or category. |
| Progress | Shows weekly consistency, the monthly calendar, active streaks, and total check-ins. |
| Habit Details | Shows the schedule, notes, and recent check-ins, with options to edit or delete the habit. |
| Habit Form | Creates or edits a habit with a category, repeat days, and optional timing details. |
